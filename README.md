# NUZI × MATTHEW – Exam Arena
نسخة أولية لموقع امتحانات الوحدة الأولى فقط.

الملفات: index.html وstyle.css وapp.js وquestions.json.
تتضمن 48 سؤالًا موضوعيًا و12 سؤالًا مقاليًا بإجابات نموذجية.
الامتحان الشامل يختار 20 سؤالًا عشوائيًا، وتدريب الدرس يعرض أسئلة الدرس. التصحيح تلقائي للاختيار من متعدد والصح والخطأ. الأسئلة المقالية للمراجعة الذاتية وليست مصححة آليًا.

## النشر المجاني عبر GitHub Pages
1. أنشئ مستودعًا عامًا على GitHub وارفع الملفات الخمسة إلى الجذر.
2. افتح Settings > Pages.
3. اختر Deploy from a branch ثم main و /(root) واضغط Save.
4. سيظهر رابط الموقع بعد اكتمال النشر.

لا يوجد في هذه النسخة تسجيل دخول أو حفظ تقدم بين الأجهزة؛ ذلك يحتاج قاعدة بيانات وخدمة خلفية. راجع الأسئلة قبل اعتمادها رسميًا، ويمكن توسيع البنك بعد التدقيق.
